# River Thread calligraphy extension

This extension keeps the selected River Thread **চ**, River Mist curve, and
tea-liquor seed while adding expressive hand-led typography. Calligraphy is
reserved for emotion, story, and collection naming; all actions and commerce
information remain in a clear sans serif.

## Page variations

| Page | Variation A | Variation B |
|---|---|---|
| About Us | `about-written-land` - origin signature | `about-inheritance` - living heritage statement |
| Products | `products-garden-edit` - curated seasonal edit | `products-steeped-season` - harvest seal |
| Cart | `cart-gathered` - selections gather on one current | `cart-ritual-awaits` - restrained invitation |
| Contact Us | `contact-write` - river-folded letter | `contact-share-cup` - hospitality and meeting currents |

Additional assets include a calligraphy specimen, packaging-style product
label, social quote card, and Assamese–Latin signature lockup.

## Calligraphic voices

- **Snell Roundhand-derived outlines:** lyrical campaign and page headlines
- **Apple Chancery-derived outlines:** readable collection and product naming
- **SignPainter-derived outlines:** informal editorial accents only
- **Kohinoor Bangla-derived outlines:** Assamese **চ**

The shipped SVGs contain outlines, not live font references. For live website
text, use the licensed/open alternatives defined in
`river-thread-calligraphy.css`.

## Usage limits

Do not use calligraphy for navigation, prices, quantities, checkout steps,
form labels, error messages, or accessibility-critical instructions. Use it
for one short phrase per viewport and preserve generous clear space.
